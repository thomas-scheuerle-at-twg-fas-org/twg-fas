# Security Policy

## Reporting Security Vulnerabilities

The Technical Working Group for Formal Automotive Systems (TWG-FAS) takes security seriously. If you discover a security vulnerability in our website, documentation, or any published materials, please report it responsibly.

### How to Report

**Do NOT** report security vulnerabilities through:
- Public GitHub issues
- GitHub discussions
- Email to general contacts
- Social media or public channels

**Instead**, please email us at: **security@twg-fas.org**

### Required Information

When reporting a vulnerability, please include:

1. **Description**: Clear explanation of the vulnerability
2. **Location**: URL or file path where the issue exists
3. **Impact**: Potential security implications
4. **Suggested Fix**: If you have one (optional but helpful)
5. **Proof of Concept**: Steps to reproduce (if applicable)

### Response Timeline

- **Acknowledgment**: Within 3 business days
- **Assessment**: Within 7 business days
- **Fix/Mitigation**: Timeline depends on severity
- **Disclosure**: Coordinated disclosure after mitigation

### Vulnerability Severity Levels

- **Critical**: Immediate risk to user data or system integrity
- **High**: Significant security risk requiring urgent fix
- **Medium**: Moderate risk, should be fixed in next release
- **Low**: Minor security issue or enhancement

### Security Best Practices

When accessing the TWG-FAS website:
- Always use HTTPS connections
- Verify you're on the official domain: `https://twg-fas.org/`
- Report any phishing attempts to: security@twg-fas.org
- Keep your browser and operating system updated

### Scope

This security policy applies to:
- This website (twg-fas.org)
- Official GitHub repositories
- Published documentation and specifications

### Disclosure Timeline

We follow a coordinated disclosure approach:

1. We receive your report
2. We confirm and assess the vulnerability
3. We develop and test a fix
4. We deploy the fix
5. We coordinate public disclosure (if applicable)
6. We credit the researcher (unless they prefer anonymity)

### Recognition

We appreciate responsible security research. If you report a valid vulnerability, we will:
- Thank you publicly (unless you prefer anonymity)
- Credit you in our acknowledgments
- Consider you for future security audits
