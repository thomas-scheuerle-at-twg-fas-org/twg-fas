# Security Policy

## Reporting a Vulnerability

The Technical Working Group for Formal Automotive Systems (TWG·FAS) takes security seriously.

If you discover a security vulnerability in:

- the TWG·FAS website
- reference implementations
- tooling
- conformance test infrastructure
- published software artifacts

please do not open a public GitHub issue.

Instead, report the issue privately to:

security@twg-fas.org

Please include:

- Description of the issue
- Affected component
- Steps to reproduce
- Potential impact
- Any proof-of-concept material

## Response Process

TWG·FAS will:

1. Acknowledge receipt as soon as practical.
2. Investigate the report.
3. Coordinate remediation where applicable.
4. Publicly disclose the issue once a fix is available or mitigations are established.

## Scope

This policy applies to:

- GitHub repositories owned by TWG·FAS
- The twg-fas.org website
- Reference implementations
- Build and publication infrastructure

This policy does not apply to:

- Third-party projects
- Vendor implementations of TWG·FAS specifications
- Independent research prototypes not maintained by TWG·FAS

## Responsible Disclosure

TWG·FAS follows a Coordinated Vulnerability Disclosure approach.

Researchers acting in good faith to improve the security of the ecosystem are welcome and appreciated.
