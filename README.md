# Technical Working Group for Formal Automotive Systems (TWG·FAS)

**An open, vendor-neutral initiative developing formal standards for AI-driven automotive systems.**

TWG·FAS aims to establish open standards for the formal representation of vehicle behavior, enabling transparent, verifiable and certifiable autonomous driving systems.

Our first major effort is the development of the **Vehicle Machine Language (VML)**—a formal intermediate representation between human engineering intent and vehicle runtime behavior.

---

## Vision

Natural language is an excellent engineering tool.

It is **not** an execution language for safety-critical systems.

TWG·FAS proposes a formal behavioral language that separates:

Human Requirements
        ↓
Foundation Models
        ↓
Vehicle Machine Language (VML)
        ↓
Formal Verification
        ↓
Vehicle Runtime

This separation enables deterministic execution, formal verification and long-term interoperability.

---

## Objectives

The working group develops open specifications for:

---

## Ethics Before Ownership

TWG·FAS is organized as an open, non-profit initiative because behavioral specifications for autonomous systems directly affect public safety. Manufacturers should be able to protect proprietary algorithms and commercial innovation, while regulators and independent experts can still review the formal behavioral intent of safety-critical systems. Open standards create this separation through transparent verification and governance without forcing disclosure of intellectual property. Openness is therefore not only a technical choice, but an ethical one.
